Photonic model loading (F13/F14) Loading the model file...

Every model on the plinth is an existing file fetched and parsed by the same call, scene.loadModel, and adopted into the scene with the standard handle, so each takes transforms, shadow flags, removal, and the baked occlusion pass like anything the creators build: the machined reference part (assets/reference-part.glb, a binary glTF with a plate, a boss, and a knob in a hierarchy, three materials, and one animation), a bracket and a wedge in binary and ASCII STL (assets/bracket.stl, assets/wedge.stl — geometry only, so both wear the engine's default material), and a knob in OBJ (assets/knob.obj) whose two groups take their colours from its material file, assets/knob.mtl.
